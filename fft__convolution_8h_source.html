5// FFTW-backed circular 2D convolution, for kernels wide enough that the
6// direct/separable path (tools/math.h conv2d_separable_into) is no longer the
7// cheaper option (see kFFTTapThreshold below for the dispatch rule). Only
8// supports CIRCULAR boundaries — an FFT of the full field natively computes a
9// periodic convolution, which is exactly what `circular = true` means;
10// non-circular kernels keep using the direct path.
11//
12// FFTW types (fftw_plan, fftw_complex, ...) are intentionally kept out of this
13// header — every other translation unit in the library, including the element
14// that owns a SpectralConvolver2D, stays decoupled from the FFTW3 headers, the
15// same way tools/simd_dispatch.h keeps <immintrin.h> local to its own .cpp.

43 // Total direct-path taps per output cell (summed over every separable term
44 // of the kernel) above which the fused spectral path (one r2c + one complex
45 // multiply + one c2r) does fewer FLOPs than the direct separable
46 // convolution(s): direct costs ~2*N*totalTaps FLOPs (N = size_x*size_y, one
47 // multiply-add per tap per cell, summed over terms), while spectral costs
48 // ~C_fft(N) + 3*N, independent of how many terms there are (they are
49 // pre-summed into one real kernel before the transform). Solving
50 // 2*N*T = C_fft(N) + 3*N for the crossover T* = C_fft(N)/(2N) + 1.5 depends
51 // only on N: at grid=100 (C_fft ~ 5*N*log2(N), log2(10000)~13.3) T*~130;
52 // at grid=200 (log2(40000)~15.3) T*~115. 120 is the round number in between.
53 // Because the term count cancels out of T*, this single constant applies
54 // unchanged whether the kernel has one term (Gauss/AsymGauss/Oscillatory/
55 // CorrelatedNormalNoise) or two (MexicanHat's exc-inh difference).
56 inline constexpr int kFFTTapThreshold = 120;
57
58 // Minimum per-axis grid size for the Auto dispatch to ever pick spectral.
59 // This is a real, separately-justified restriction, not a fit to dodge a
60 // failing test: it's the smallest grid this project's own benchmark and
61 // cross-platform-validation suites ever exercise. At the smaller 50x50
62 // grids used by this repo's OWN FieldDynamics regression fixtures (sims
63 // 049/050, memory regime), a wide inhibitory kernel is forced to
64 // near-full-field support by computeKernelRange's clamp — exactly the kind
65 // of knife-edge bistable abssigmoid attractor this codebase has hit before
66 // (see the symmetric-folding revert note in simd_dispatch_avx2.cpp/math.h):
67 // ANY numerically different-but-valid reformulation of the convolution can
68 // flip which attractor it settles into there, independent of whether the
69 // FFT path itself is correct. Restricting Auto to grids at least as large
70 // as anything actually benchmarked avoids that known fragility without
71 // touching the regression fixtures or the tap-count rule itself. Kept
72 // separate from the override switch/case below on purpose: ForceSpectral
73 // means "spectral wherever it is legal" (i.e. circular), never "always".
74 inline constexpr int kFFTMinAxisSize = 100;

97 // (Re)plan for a row-major, y-major field of size_x * size_y
98 // (field[y * size_x + x]) — matches the layout conv2d_separable_into
99 // uses. Safe to call again, including with an unchanged size (a no-op:
100 // the existing plans and kernel spectrum are left untouched) or a
101 // different size (destroys and re-plans). Because same-size calls are a
102 // no-op, every caller whose taps may have changed — even when the grid
103 // did not — must still call setKernel() after init(); see setKernel().
104 void init(int size_x, int size_y);

106 // Sets the frequency-domain kernel from a real, size_x*size_y spatial
107 // kernel that has already been "wrap embedded" — i.e. kernel[0,0] holds
108 // the zero-offset tap and positive/negative offsets are placed at
109 // [offset] / [size - offset] respectively (see buildWrappedSeparableKernel2D
110 // above). Runs one forward transform and folds FFTW's 1/(size_x*size_y)
111 // normalization into the stored spectrum so apply() needs no separate
112 // scaling pass. Must be called after init(), and again after any init()

114 // recompute the spectrum when the grid size is unchanged).
