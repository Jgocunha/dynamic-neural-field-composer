6// OpenCV/FFTW select their SIMD code path at runtime rather than at compile time,
7// so a single dnf-composer binary runs correctly on any x86-64 CPU instead of
8// requiring AVX2 to be present at all (see TRADE_OFF_CAVEATS.md in the benchmark
9// repo for why this matters).

13// file (including this header's caller, tools/math.h) is compiled at the
